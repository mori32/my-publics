# coltIme

**文脈を読んで、打ちたい言葉を提案するWindows向け日本語IME。**

「AIが文章の流れを読めるなら、日本語入力でも気を利かせてほしい。」そんな思いから作り始めました。

海産物の話をしているときの「かき」と、果物の話をしているときの「かき」。読みは同じでも、話題が分かれば選べそうです。coltImeは、いつもの辞書変換にAI予測を組み合わせて、今書いている文章に合う言葉や、その続きを提案します。

このリポジトリは、coltImeの配布と、不具合・誤変換・要望の受付に使っています。

[ダウンロード](https://github.com/mori32/my-publics/releases) · [誤変換の報告](https://github.com/mori32/my-publics/issues/22) · [不具合・要望](https://github.com/mori32/my-publics/issues)

## 特徴

- **文脈を使うAI予測。** 入力中の読みや直前に確定した文章、アプリから取得できる本文を参考に、OpenAI APIで候補を生成します。
- **入力中は辞書ですぐ変換。** AIの応答を待たずに入力できます。AI予測をOffにしても、辞書変換・辞書予測を使えます。
- **辞書変換も地道に改善。** 約1億文のコーパスとCRF学習を土台に、語彙や言葉のつながりを改善しています。

AI変換IMEを作り始めたはずが、気づけばコーパスの補修と辞書作りにもどっぷり。毎日使う道具として、両方を育てています。

## 使ってみる

対象はWindows x64です。WebView2 Runtimeが必要です。

1. [Releases](https://github.com/mori32/my-publics/releases)から、使いたい版の `coltIme-{version}-windows-x64.msi` をダウンロードします。
2. 同じリリースの説明と `INSTALL.txt` を確認して、インストールします。
3. 導入後はサインアウト・サインインし、Windowsの入力切り替えからcoltImeを選びます。

署名状態や対応環境、更新時の注意点は、ダウンロードする版のリリース説明を確認してください。

## AI予測について

AI予測の利用には、ご自身のOpenAI APIキーとAPIの利用料金が必要です。coltImeの設定画面でキーを設定してください。

AI予測を有効にすると、候補生成のために入力中の読み・直前の確定文章・取得した文書の文脈をOpenAIへ送信します。利用しない場合は設定でOffにできます。Offでも辞書変換・辞書予測は使えます。

## 不具合・誤変換・要望

まだ改善を続けているIMEです。使っていて気になったことを教えてもらえるとうれしいです。

- **誤変換・候補不足：** [誤変換の報告ストック #22](https://github.com/mori32/my-publics/issues/22)へコメントしてください。入力した読み、実際の結果、期待する表記があると調査しやすくなります。
- **その他の不具合・要望：** [Issues](https://github.com/mori32/my-publics/issues)へ、件名に `[coltIme]` を付けて登録してください。使用バージョンや発生したアプリも、分かる範囲で添えてください。
